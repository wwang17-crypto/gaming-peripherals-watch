The one Logitech-adjacent development worth logging is software someone else is writing. OpenMouse, announced Aug 4, is a hardware-agnostic, open-source, browser-based mouse control panel built on WebHID — no install, works on Windows, macOS and Linux from any Chromium browser. Its launch device list already includes the Superlight 2C, Superlight 2 and the PRO X2 Superstrike alongside WLMouse, Endgame Gear, Pulsar and Orbital hardware, and the project's own X account says support for HITS — Logitech's Haptic Inductive Trigger System, the entire reason the Superstrike costs $179.99 — is incoming. Two things matter here and they point in opposite directions. First, this is reverse-engineering, not partnership: Logitech has published no HITS configuration protocol for third parties, the project is still pre-early-access with Buttons and Profiles tabs visibly unfinished, and until there are signed Windows builds G HUB remains the only supported path for Superstrike owners. Second, and more consequential, the fact that an unpaid open-source project targets the Superstrike first is a market read on G HUB — and it lands in the same week CORSAIR shipped an entire entry tier configurable through a browser with no install at all, and one week before the EU CRA clock starts on exactly the class of privileged, self-updating, firmware-pushing desktop software G HUB is. The driver is being attacked from three directions at once: a competitor deleting it, a community replacing it, and a regulator scoping it.
