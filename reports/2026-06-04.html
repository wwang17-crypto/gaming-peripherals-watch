Cherry XTRFY

K63W Pro Compact Ultra-Wideband

Keyboard

World's first 8K-polling wireless gaming keyboard built on Ultra-Wideband (UWB) instead of 2.4 GHz — short-burst transmission across a wide frequency spectrum that Cherry claims removes the interference / contention that has historically forced wireless gaming keyboards to either drop polling or pin to wired mode. 70% layout (F-row retained, nav cluster + arrows dropped), MX Low Profile 2.0 mechanical switches, gasket-mounted case, 6,000 mAh battery for ~1,100 h continuous wireless operation. First high-polling-rate keyboard implementation of UWB after select gaming mice; positioned squarely against Logitech's $169.99 G PRO X TKL Rapid (which still polls at 1000 Hz) at the same MSRP.

Wooting

Lekker Knob (large) · 80HE accessory

Keyboard

Wooting's first programmable input knob ships as a drop-in 80HE accessory, replacing the four-key nav cluster above the arrow keys. Four programming modes in Wootility — Relative (per-step fires), Absolute (per-position fires), Zoned (slice-and-tap), and Analog (analog input strength) — plus layered modifiers (Ctrl + turn fires a different action than Alt + Ctrl + turn). Wooting's lead software engineer demoed steering-wheel-input experiments and an "Alt+F4 roulette" zone game on the floor; small single-key variant for other Wooting boards still in development. Three years of internal R&D; ship target is end of 2026. Compatible with ~98% of Wooting's installed base (ARM-chip boards); first-gen AVR boards excluded.
